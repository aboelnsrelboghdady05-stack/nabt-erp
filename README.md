# 🌸 نظام نَبْتْ المتكامل لإدارة محلات الورد والمناسبات (Nabt Flowers ERP)

نظام ERP سحابي متكامل ومخصص لطبيعة عمل محلات الورد، تنسيق الزهور، والهدايا. يربط بين **الطلبات، العملاء، المناديب، شات وإشعارات الواتس اب، ونظام الحسابات والفواتير والتحصيل** في لوحة تحكم ذكية واحدة.

---

## 🌟 أبرز مميزات النظام والربط المتكامل:

### 1. 📊 لوحة التحكم الشاملة (Executive Dashboard)
- **مؤشرات المبيعات المباشرة**: مبيعات اليوم، مبيعات الشهر، إجمالي المبالغ المحصلة، وصافي الربح بعد خصم المصروفات.
- **متابعة تدفق الطلبات**: عدادات حية لحالات الطلبات (طلب جديد 🟡، قيد التنسيق 🌿، جاهز للتسليم 🌸، مع المندوب 🚗، تم التوصيل 💐، ملغي ❌).
- **جدول الطلبات المستعجلة لليوم**: متابعة الطلبات وتغيير حالتها بضغطة زر.
- **تنبيهات مناسبات العملاء السنوية**: تذكير بأعياد ميلاد وذكرى زواج عملاء VIP لإرسال عروض وتنسيقات زهور مخصصة عبر الواتساب.
- **إحصائيات المنتجات**: أكثر باقات الورد والهدايا طلباً.

### 2. 🌸 إدارة الطلبات وتنسيق الورد (Orders & Floristry)
- نافذة مخصصة لإدخال طلبات الورد تشمل:
  - تفاصيل الباقة والزهور والكميات مع خصم المخزون تلقائياً.
  - كرت الإهداء المخصص (طباعة العبارة على كرت الهدايا المختوم).
  - تحديد طالب الهدية (العميل) والمستلم النهائي وعنوانه ولوكيشن خرائط جوجل.
  - تحديد موعد وفترة التوصيل (صباحي، مسائي، فوري عاجل).
  - إسناد الطلب للمندوب المناسب.
  - حساب ضريبة القيمة المضافة (15% VAT) ورسوم التوصيل والخصم تلقائياً.
- تحديث فوري للحالة يطلق إشعار واتساب تلقائي مخصص للعميل والمندوب.

### 3. 💬 مركز محادثات الواتس اب والإشعارات الآلية (WhatsApp Center)
- **ربط مباشر عبر مسح رمز الاستجابة السريعة (QR Code)** مثل واتساب ويب بدون أي اشتراكات خارجية.
- **إشعارات تلقائية فورية**:
  - رسالة تأكيد الطلب مع تفاصيل الفاتورة.
  - رسالة بدء تنسيق وتجهيز باقة الورد.
  - رسالة انطلاق المندوب مع رقم هاتفه للتواصل.
  - رسالة تم توصيل الهدية بنجاح وشكر العميل.
  - رسالة فورية للمندوب ببيانات المستلم ولوكيشن خرائط جوجل بنقرة زر.
- **شات مباشر متكامل**: إجراء محادثات مباشرة مع العملاء من داخل السيستم، مع ردود سريعة وقوالب جاهزة، وخيار الانتقال المباشر لتطبيق واتساب.

### 4. 🧾 نظام الحسابات والفواتير وسندات القبض (Accounting & Invoices)
- **فواتير مبيعات إلكترونية معتمدة**: متوافقة مع متطلبات هيئة الزكاة والضريبة والجمارك (ZATCA) متضمنة رمز QR Code مشفر بالمعايير القياسية (TLV Base64).
- **تتبع حالة السداد**: فواتير مسددة بالكامل، مسددة جزئياً، أو غير مسددة (آجلة).
- **تسجيل سندات القبض والدفعات**: تسجيل سداد العملاء (نقداً، شبكة/مدى، تحويل بنكي) وتوليد سند قبض تلقائي وتحديث مديونية الفاتورة وإرسال إشعار السند للعميل بالواتساب.
- **معاينة وطباعة الفاتورة وبوليصة التوصيل وكرت الإهداء**.

### 5. 🚗 المناديب واللوجستيات (Drivers & Logistics)
- متابعة حالة المناديب (متاح للتوصيل، في مشوار توصيل، خارج الدوام).
- حساب عدد التوصيلات المكتملة وإجمالي العمولات المستحقة لكل مندوب.
- زر إرسال مباشر لتفاصيل وموقع الطلب للمندوب عبر الواتساب.

### 6. 👥 إدارة علاقات العملاء (CRM & Occasions)
- حفظ سجل العملاء، إجمالي مشترياتهم وعدد طلباتهم.
- تسجيل المناسبات السنوية الخاصة بالعميل (ذكرى زواج، يوم ميلاد، تخرج).

### 7. 💸 المصروفات والأرباح الصافية (Expenses & P&L)
- تسجيل فواتير شراء الورد الطبيعي المستورد، مواد التغليف والشرائط، الإيجارات، الرواتب، وتبريد المعرض.
- تقرير مالي بحجم المصروفات ومقارنتها بالإيرادات لاحتساب صافي الأرباح.

## 🚀 طريقة تشغيل السيستم:

### الخيار 1: عبر سكريبت التشغيل المباشر
افتح الطرفية (Terminal) داخل مجلد المشروع ثم اكتب:
```bash
./start.sh
```

### الخيار 2: تشغيل يدوي عبر بايثون
```bash
# تفعيل البيئة وتشغيل السيستم
./venv/bin/python run.py
```

بعد التشغيل، افتح المتصفح على الرابط التالي:
👉 **http://localhost:8000**

---

## 🛠️ البنية التقنية للمشروع:
- **Backend**: Python 3 (FastAPI, Uvicorn, SQLite WAL, Jinja2, Pillow, QRcode)
- **Frontend**: Responsive Single Page App (Tailwind CSS, Lucide Icons, RTL Arabic Typography)
- **Database**: SQLite `nabt_erp.db` (مهيأة ومحملة ببيانات تجريبية جاهزة للعمل فوراً)
