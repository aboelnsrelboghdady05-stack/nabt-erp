ربط برنامج الحسابات (Webhook Integration)

استقبال الفواتير الصادرة من قيود، دفترة، أودو، أو زوهو آلياً فور إصدارها

قم بوضع هذا الرابط في قسم الـ Webhooks في برنامج الحسابات لديك مع حدث: Invoice Created / فاتورة جديدة.

خطوات تفعيل الربط في برامج الحسابات الشائعة:

١. قيود (Qoyod):

من الإعدادات ← التطبيقات و Webhooks ← إضافة Webhook جديد ← الصق رابط الاستقبال واختر الحدث (إنشاء فاتورة مبيعات).

٢. دفترة (Daftra):

من الإعدادات ← قواعد العمل التلقائية / API ← عند إضافة فاتورة جديدة ← إجراء: إرسال Webhook POST لرابط السيستم.
